# HoneyVoice VST3

Lyric-by-lyric vocal creative FX plugin inspired by iZotope Nectar Moments, built with JUCE 8 and CMake.

## Quick Build via GitHub Actions
1. Upload the contents of this archive to `https://github.com/AlexanderSeel/HoneyVoice` (preserving `.github/workflows/build.yml`).
2. Open the **Actions** tab on GitHub and wait ~4–5 minutes for **Build HoneyVoice VST3** to complete.
3. Download **`HoneyVoice-VST3-windows-latest`** or **`HoneyVoice-VST3-macos-latest`** under **Artifacts**.
4. Copy `HoneyVoice.vst3` to your system VST3 folder:
   - **Windows:** `C:\Program Files\Common Files\VST3`
   - **macOS:** `/Library/Audio/Plug-Ins/VST3`
